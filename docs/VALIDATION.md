- `code/README.md`: 현재 채널 알림·공유 보고서·예약 확인 범위를 반영.
- `code/.env.funding.example`: 이전 수집기용 설정임을 표시하고 공모전·채용 채널 예제를 보완.
- `code/discord-notifier/README.md`: 폴더 업로드 안내 및 Vercel 봇 토큰 유지 조건 정정.
- `code/docs/vercel-html-reports.md`: 현재 일정·채널 전송 방식 정정.
- `code/docs/dots-daily-brief.md`, `code/docs/dots-personal-brief.md`: 08시 조사·09시 보고 분리, 기존 예약 유지, 즉시 재발행 방지.
