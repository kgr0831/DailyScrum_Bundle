# dots에 전달할 프롬프트

- **겜마루 예약:** [01-gammaru.md](01-gammaru.md)의 텍스트 블록 전체
- **공모전·채용 예약:** [02-personal.md](02-personal.md)의 텍스트 블록 전체

두 프롬프트를 같은 예약에 합치지 않습니다. 공모전·채용 공간의 경로는 `/personal`이지만 현재는 Discord 로그인 이용자가 함께 읽는 보고서이며, 상태·메모만 계정별입니다.

각 문서는 상세 지침의 조사·발행 절차를 담고, 현재 일정인 **08시 조사·09시 보고(Asia/Seoul)**를 유지하도록 정리했습니다. 사용자 PC가 아닌 dots 클라우드에서 진행하며 매번 사이트의 최신 지침·진행 기록을 읽습니다.

예약용 문서는 새 AWS 주소 `https://d3ktbkaahtexzk.cloudfront.net`을 사용합니다. 기존 예약이 있으면 [주소 변경 전달문](../code/docs/dots-aws-switch.md)을 전달하고 클라우드에서 다시 로그인하세요. AWS 사이트는 준비됐고 dots 예약 변경은 여기서 직접 실행하지 않았습니다.

업로드 키는 포함하지 않습니다. 두 공간은 서로 다른 업로드 키를 사용하며 비공개 로그인에서 직접 입력합니다. 관리자·Discord·Blob 토큰을 붙여넣지 않습니다.

프롬프트 전달만으로 예약이 저장되었다고 판단하지 말고, dots가 반환하는 예약 이름·활성 상태·시간대·다음 실행 시각을 확인합니다. 이번 보관본 작성에서는 예약을 변경하지 않았습니다.
